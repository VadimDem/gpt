# Пример веб-платформы на Flask

Этот репозиторий содержит небольшой пример сайта для каталога бытовых товаров. Приложение запускается локально на Python с использованием Flask и сохраняет данные в SQLite.

## Установка

1. Установите Python 3.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install Flask
   ```

## Инициализация базы данных

В каталоге `webapp` запустите скрипт инициализации:
```bash
python init_db.py
```
Он создаст файл `database.db` и наполнит его тестовыми товарами.

## Запуск

Перейдите в каталог `webapp` и выполните:
```bash
python app.py
```
Сайт будет доступен по адресу <http://127.0.0.1:5000>.

## Структура проекта
```
webapp/
    app.py
    init_db.py
    database.db (создаётся автоматически)
    templates/
        base.html
        index.html
        product.html
    static/
        style.css
        images/    # сюда нужно поместить картинки товаров
```

Теперь товары хранятся в базе данных SQLite. Изображения нужно самостоятельно разместить в каталоге `static/images` под теми же именами.
