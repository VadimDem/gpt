# Пример веб-платформы на Flask

Этот репозиторий содержит пример локальной веб‑платформы для продажи бытовых товаров. Приложение запускается на Python с использованием Flask и сохраняет данные в SQLite. Поддерживаются регистрация пользователей, вход, корзина и поиск товаров.

## Установка

1. Установите Python 3.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install Flask
   ```

## Инициализация базы данных

В каталоге `webapp` запустите скрипт инициализации:
```bash
python init_db.py
```
Он создаст файл `database.db` и наполнит его тестовыми товарами.

## Запуск

Перейдите в каталог `webapp` и выполните:
```bash
python app.py
```
Сайт будет доступен по адресу <http://127.0.0.1:5000>.

После запуска перейдите на страницу регистрации и создайте аккаунт. Авторизовавшись, вы сможете добавлять товары в корзину и оформлять заказ.

## Структура проекта
```
webapp/
    app.py
    init_db.py
    database.db (создаётся автоматически)
    templates/
        base.html
        index.html
        product.html
    static/
        style.css
        images/    # изображения товаров, которые вы добавите
```
В каталог `static/images` поместите изображения с именами `bucket.png`, `mop.png`, `sponge.png`, `broom.png`, `detergent.png`, `gloves.png`, `brush.png`, `trashbags.png`, `cloth.png` и `cleaner.png`.
