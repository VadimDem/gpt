# Пример веб-платформы на Flask

Этот репозиторий содержит минимальный пример сайта для демонстрации каталога
бытовых товаров. Приложение работает локально и написано на Python с
использованием фреймворка Flask.

## Установка

1. Установите Python 3.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install Flask
   ```

## Запуск

Перейдите в каталог `webapp` и выполните:

```bash
python app.py
```

Сайт будет доступен по адресу <http://127.0.0.1:5000>.

## Структура проекта

```
webapp/
    app.py
    templates/
        base.html
        index.html
        product.html
    static/
        style.css
```

Товары хранятся в списке внутри `app.py` и служат для примера. Вы можете
добавить свои данные или подключить базу данных для более сложного проекта.
